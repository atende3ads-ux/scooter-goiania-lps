# Landing Pages - Scooter Goiânia

Conjunto de quatro landing pages estáticas para a Scooter Goiânia:

- Scooters e bikes elétricas
- Triciclos elétricos
- Patinetes, hoverboards e triciclos drift
- Oficina especializada

As páginas usam HTML, CSS e JavaScript puros, sem dependências de build. Os dados e as imagens dos produtos foram atualizados a partir do catálogo 2026 fornecido pela loja.

## Estrutura

- `/scooters-e-bikes/`
- `/triciclos/`
- `/diversao-eletrica/`
- `/oficina/`

## Desenvolvimento local

```bash
python3 -m http.server 4173
```

Depois, acesse `http://localhost:4173`.
